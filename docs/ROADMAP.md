# Roadmap
1. **MVP**: catálogo verificable, fichas, filtros, calculadora, SEO y actualización validada.
2. **Cobertura**: SNPSAP, BOE XML, tres CCAA piloto, histórico de cambios y alertas de enlaces rotos.
3. **Cuenta opcional**: Supabase/PostgreSQL, favoritos, alertas y consentimiento explícito.
4. **Facturas**: OCR seguro, confirmación humana y borrado automático.
5. **Monetización**: feeds Awin/Amazon, etiquetado de afiliación y ranking editorial independiente.
